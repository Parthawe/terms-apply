Terms Apply

A tabletop game about acquiring convenience and keeping track of what comes with it.

What comes with convenience?

A writing service can accelerate a task and still leave a claim to check. Memory can preserve a return point and still need acknowledgement. Terms Apply makes those obligations part of the next decision.

Players have four rounds to complete fictional tasks. They acquire shared services, use time, inspect evidence, and decide whether an answer is ready. A supported “not enough information” conclusion can count as a completed task.

This is a working digital prototype and printable kit. The physical components have not been fabricated or tested with participants.

Paperwork becomes a game piece

The receipt records actions. Service cards carry benefits and terms. Source cards let players inspect an answer. A routing choice and a saved return point become obligations on the shared workbench.

The first version uses a square track, document-sized cards, and a restrained ink palette. The board makes acquisition familiar while the shared workbench holds what remains unfinished.

The experience ends after four rounds. It rewards usable task outcomes and clear obligations rather than accumulating the most property.

AI players at the table

The live arena runs independent player workspaces around one shared board. Each player receives the same dice rolls and task evidence. The referee records their actions, completed tasks and open obligations.

Local strategy bots demonstrate continuous play. OpenRouter mode requests moves from selected models, with an inspectable transcript and daily API limits. Actual model play requires a server key; it has not been verified yet.

What still needs testing

The core interactions work in the browser. Balance, rule clarity, session duration, and whether the physical record communicates accumulated work still need participant playtesting.

  • Does each service feel useful enough to acquire?
  • Can players anticipate a service’s obligation before using it?
  • Does source checking feel meaningful rather than repetitive?
  • Are unfinished tasks and open terms easy to find after interruption?

The time counters are game units. They are not measurements of actual productivity, attention, or emotional outcomes.
