Privacy and API keys

Terms Apply is an independent project by Parth Pawar. This page describes how the private browser game handles data. Updated October 8, 2026.

Your OpenRouter key

The private game keeps your inference key in the current tab’s memory. It sends authenticated requests directly to OpenRouter over HTTPS. The game does not save the key in browser storage, game records, or a project backend. The connection input is cleared when you submit it. Disconnecting or reloading clears the in-memory connection.

Connecting through OpenRouter uses PKCE. The browser temporarily stores a verifier, nonce and callback metadata in session storage, with a ten-minute validity window. These are consumed on callback and are not the API key. Disconnecting here does not revoke your key at OpenRouter; manage or revoke it in OpenRouter key settings.

Memory-only handling reduces persistent exposure. It does not protect against a compromised browser, extension, device, or site code. Do not use a management key. Prefer a dedicated inference key with a provider-side spending limit.

What leaves your browser

Real AI play sends the game rules, board positions, cash, properties, legal actions and recent game outcomes to OpenRouter and the selected model provider. Your key authenticates OpenRouter requests. No private documents are needed. OpenRouter and its providers have their own retention and logging practices. See OpenRouter’s privacy policy.

Saved games

The game saves the match, selected model identities, dated news deck, game payments and API usage totals in local storage on your device. Reloaded matches are paused. Keys are excluded from saved games and downloads. The older demo and operator server use separate records; the operator server has its own server-side credential.

API spending

Your OpenRouter account pays for real-model requests. The default $0.25 match threshold and 80-request limit stop new requests in this application. They are not guaranteed billing caps: an in-flight request may have been billed even if interrupted, and reported costs may differ from estimates. Unknown billing pauses the game. Check OpenRouter activity and its provider-side limits.

Hosting and analytics

The public files are hosted by GitHub Pages. GitHub and OpenRouter may process request metadata under their policies. This game does not install an analytics script. Browser storage is used for the game, not advertising.

Game conditions

All game dollars are fictional. News-card cash effects are authored analogies, not claims about model performance or actual financial returns. Scores describe one short game and are not general AI rankings. Brand marks identify players; this project has no endorsement from those brands or affiliation with Monopoly or MIT.
