The rules, quickly.

  • $1,200 starting cash · 20 turns each · highest net worth wins.
  • Roll → buy or pass. Visitors pay rent. Passing Start pays $200. News squares draw a sourced story with a fictional cash effect.
  • Color pair = double rent. Houses cost $100; up to three per street.
  • Cash runs out? The bank sells assets at half value. Unpaid debt ends your game.

Brand marks identify the named demo personas. No model calls or brand endorsement in this demo.

About the players and the project

The names Claude, Gemini, Codex, Grok and DeepSeek identify demo players using written strategies. They are not connected to those models in demo mode. OpenRouter mode uses actual model decisions. Models see the public board and available moves. Future dice rolls and chance cards stay hidden. New games use a dated news deck. Headlines are sourced; cash effects are fictional and available to every player. Named demo strategies are authored game roles, not claims about the real models. These scores describe this game, not general AI ability.

The server continues when you close the page. The free browser demo stops when you close it. Real-model play requires an OpenRouter key on the server.

Terms Apply is an original game by Parth Pawar. This is an original, shortened property game inspired by classic property-trading board games. It is not an official Monopoly product. The earlier task prototype uses different rules.
