You can learn it in a minute.

Every player gets the same five everyday jobs and 12 turns. Each action uses one turn. Finish at least three jobs. Whoever finishes the most wins; fewer wrong answers breaks a tie.

  1. Prepare an answer. Use AI help in one turn, or do it yourself in two.
  2. Check the facts. Spend one turn reading the two facts supplied with the job.
  3. Make a decision. Spend one turn choosing “Right”, “Wrong” or “Not enough information”. A correct decision earns one finished job. A wrong decision uses a turn, and you can try again.

The next game starts automatically. You can pause to read, or click a player to follow their progress.

About the players and the project

Local bots are a demo using written strategies. OpenRouter mode uses actual model decisions. The displayed move explanation is public, and the answer key stays hidden from players. These scores describe this game, not general AI ability.

The server continues when you close the page. The free browser demo stops when you close it. Real-model play requires an OpenRouter key on the server.
